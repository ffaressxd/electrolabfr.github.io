منصة تعليمية مبسطة لمشاريع ودروس الهندسة الكهربائية والأنظمة الآلية.

درس: نظام الغسالة الآلي

الغسالة الآلية هي نظام يستقبل مجموعة من المدخلات، ثم يعالج هذه المعلومات ويحدد البرنامج المناسب لتنفيذ عملية الغسيل.

مراحل عمل النظام

يعتمد النظام على ثلاث مدخلات رئيسية:

1. نوع المادة
2. درجة الاتساخ
3. وزن الملابس

بعد الحصول على هذه المعلومات يقوم النظام بتحليلها وتحديد برنامج الغسيل المناسب، مثل درجة حرارة الماء، مدة الغسيل وسرعة الدوران.

كود Python للنظام


def washing_machine(material, dirt_level, weight):

    if material == "cotton":

        if dirt_level == "light":
            if weight <= 5:
                temperature = 30
                duration = 45
                rpm = 800
            else:
                temperature = 40
                duration = 55
                rpm = 900

        elif dirt_level == "medium":
            temperature = 40
            duration = 65
            rpm = 1000

        else:
            temperature = 60
            duration = 80
            rpm = 1000

    elif material == "synthetic":

        if dirt_level == "light":
            temperature = 30
            duration = 40
            rpm = 700

        elif dirt_level == "medium":
            temperature = 40
            duration = 55
            rpm = 800

        else:
            temperature = 40
            duration = 70
            rpm = 900

    elif material == "wool":

        temperature = 30
        duration = 35
        rpm = 500

    else:

        temperature = 30
        duration = 45
        rpm = 600

    return temperature, duration, rpm

ملاحظة

هذا الكود يمثل الجانب البرمجي من النظام الآلي. أما تجربة الغسالة الموجودة في الصفحة الأخرى فهي محاكاة تفاعلية للنظام ولا تعرض الكود للمستخدم.
